[ADR-0011](../design/decisions/ADR-0011-background-response-contract.md) records
the owner's 250 ms response allowances. [ADR-0012](../design/decisions/ADR-0012-cooperative-cancellation-contract.md)
records the explicit cooperative-completion choice. Protocol v6 treats a
correct normal return with no request within B+250 ms as NOT_TRIGGERED,
never actual-cancellation evidence. Issued requests and FIRST/HALF must
actually cancel. Elapsed-budget memory growth observations, six fixed
allocator samples and all other native purposes remain mandatory. The exact
policy SHA-256 is `095dcfe24a732106a0b633902f2932aadcc8de8c179f8e3d1f76c9c9b9861430`.

The claim is **functional equivalence within the registered validation scope**:
V0-V6 and V10, with L1 syntax provenance and L3 pinned native tools. Equal
absolute latency across machines, unrestricted-input behaviour, Roku device
compatibility (V8) and downstream `go-treesitter` integration (V9) are not claimed.
macOS supervision is a measured sampling limit, not an instantaneous hard cap.
