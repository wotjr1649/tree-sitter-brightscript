## What changed

- **Schema re-freeze** ([tree-schema.md](../specs/tree-schema.md) "Re-freeze
  of 0.1.0"): a called member is one `call_expression` with `object`,
  `property` and `arguments`; PRINT items are direct children of
  `print_statement` without an `expression` wrapper; six error-only named
  forms (`open_parenthesis`, `open_bracket`, `minus_sign`, `plus_sign`,
  `not_operator`, `try_keyword`) appear only inside `ERROR` nodes. Every
  valid public tree projects onto the earlier schema without loss
  (SEM-PUBLIC below).
- **Error-recovery scanner** (grammar-design §16): in the runtime's error
  state only, the rest of a malformed physical line is one hidden token and a
  line break ends the error, so recovery resumes on the next line. It
  produces no token in a valid parse.
- **Stack and node reductions**: block headers as hidden rules and
  `_block_head`; six inlined helpers.
- **Query**: sibling-order patterns for method calls and the error-only
  forms; W11 unchanged in meaning.

## Known limitations and disclosures

- A malformed line becomes one `ERROR` node; the tokens after the error point
  on that line are no longer separate nodes (roles above).
- Below more than 16 unclosed constructs the runtime finds no state that
  accepts the line break, and the following lines are absorbed into the error
  as before the scanner (grammar-design §16; `L-WHILE` 1 MiB: 1.13 s,
  145 MiB, within LARGE-INPUT).
- The A5-01 pair exponents depend on host cache behaviour near 16,000 items;
  the BEFORE_PRINT reference shows the same step.
- The lane runs on the local Windows host; hosted CI runs its CLI subset. The
  support runtimes are checked for completion within the caps only.
- Earlier limitations and requirement statuses are unchanged
  ([0.1.0-release.md](0.1.0-release.md#known-limitations)), except KL-002.
